# Deployment Guide

## Requirements

* Java 17+
* Maven
* Docker Desktop

## Project Setup

### 1. Start MySQL

Run the MySQL container:

```bash
docker compose up -d
```

Verify:

```bash
docker ps
```

Expected container: `bookstore_mysql`

### 2. Run Spring Boot

```bash
mvn spring-boot:run
```

or

```bash
mvn clean package
java -jar target/bookstore-1.0.0.jar
```

### 3. Open Application

Default URL:

http://localhost:8080

## Database Initialization

The database schema is automatically created from: `database/schema.sql`

Sample data is automatically generated by `DatabaseSeeder` during application startup.

## Reset Database

To recreate the database from scratch:

```bash
docker compose down -v
docker compose up -d
```

Then restart the Spring Boot application.
